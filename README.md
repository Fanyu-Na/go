# 围棋 · 五子棋 纯前端版

从 GO_v1 桌面版 (Pygame + AI 模型) 中提取的**纯静态网页版**，
只保留围棋基础规则与界面设计，**不需要 Python、后端服务或任何模型文件**。

## 使用方法

直接用浏览器打开 `index.html` 即可（双击即可，`file://` 协议可用）。

推荐 Chrome / Edge / Firefox 等现代浏览器；也支持手机浏览器（窄屏自动上下布局）。

## 部署到 Vercel

纯静态站点，**无构建步骤、零依赖**，两种方式任选：

### 方式一：Vercel CLI（最快）

```bash
cd frontend_html
npx vercel          # 首次会引导登录并创建项目，之后 npx vercel --prod 上线
```

### 方式二：GitHub 导入

1. 把 `frontend_html/` 推到一个 Git 仓库（或推整个 GO_v1 仓库）；
2. 在 [vercel.com](https://vercel.com) → **Add New → Project** 导入该仓库；
3. 若导入的是整个 GO_v1 仓库，在 **Root Directory** 填 `frontend_html`；
   Framework Preset 保持 **Other**，构建命令与输出目录全部留空；
4. 点 **Deploy** 即可，之后每次 push 自动重新部署。

`vercel.json` 已配置：HTML 不缓存（改版即时生效）、css/js 缓存 1 小时、
去除 `.html` 后缀。

## 功能

- **围棋**（9 / 13 / 19 路双人对战）
  - 中国规则数子法：子 + 单方围空 + 贴目（9 路 5.5 / 13 路 6.5 / 19 路 7.5）
  - 禁自杀、简单劫（禁止立即回提）、双停一手自动数子并展示领地
  - 「数目」按钮可随时查看当前领地划分与双方点数
- **五子棋**（15 路自由规则）
  - 双人对战，或挑战内置启发式 AI（攻防棋型评分，无神经网络）
  - 人机模式下可「预测着法」（AI 建议点脉冲高亮 6 秒）、交换执子
- **通用**
  - 悔棋（人机模式自动连 AI 的应手一起撤销）、认输、复盘逐手回放
  - SGF 棋谱保存 / 导入（围棋 GM[1] 中国规则、五子棋 GM[4]，主变解析）
  - WebAudio 合成音效（点击 / 落子 / 提子 / 终局），可开关
  - 键盘：`R` 新对局 · `U`/退格 悔棋 · `A` 预测 · `C` 交换执子 · `D` 数目 ·
    `P` 复盘 · `S` 保存 · `空格`/`←`/`→` 复盘逐手 · `Esc` 退出/返回
  - 菜单支持 `←`/`→` 选择、`Enter` 确认、`Esc` 返回

## 目录结构

```
frontend_html/
├── index.html        页面骨架（菜单视图 / 对局视图 / 隐藏 SGF 文件框 / 模态框挂载点）
├── css/style.css     全部样式（深色菜单 + 象牙色信息栏 + 木纹棋盘配色）
├── js/
│   ├── sound.js      WebAudio 合成音效（无音频文件）
│   ├── go_env.js     围棋规则引擎（提子 / 劫 / 禁自杀 / 数子 / 领地）
│   ├── gomoku_env.js 五子棋规则引擎（四方向连五判定）
│   ├── gomoku_ai.js  五子棋启发式 AI（纯算法，无模型）
│   ├── sgf.js        SGF 保存 / 下载 / 主变解析
│   ├── ui.js         棋盘 Canvas 绘制 + 主菜单 + 确认框
│   └── main.js       对局流程控制器（事件 / 侧栏 / 复盘 / 键盘）
├── vercel.json       Vercel 部署配置（缓存策略 / cleanUrls）
└── README.md
```

> 说明：脚本均为普通（非 module）脚本并按固定顺序加载，因此无需本地服务器，
> 直接以 `file://` 打开即可运行。
