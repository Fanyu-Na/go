# 围棋 · 五子棋 网页版

从 GO_v1 桌面版 (Pygame + AI 模型) 中提取的网页版，
只保留围棋基础规则与界面设计，**不需要 Python 或任何模型文件**。

本地双人 / 人机对局为纯静态页面；**联机对战**经 Vercel Functions + Blob
服务器中继（接口就在本项目 `api/` 目录里，随站点一起部署，**无需另外架设服务器**）。

## 使用方法

本地对局：直接用浏览器打开 `index.html` 即可（双击即可，`file://` 协议可用）。
联机对战：需按下方步骤部署到 Vercel（并关联一次 Blob 存储）后访问。

推荐 Chrome / Edge / Firefox 等现代浏览器；也支持手机浏览器（窄屏自动上下布局）。

## 部署到 Vercel

纯静态站点 + 联机中继接口（Vercel Functions），**无构建步骤**，两种方式任选：

### 方式一：Vercel CLI（最快）

```bash
cd frontend_html
npx vercel          # 首次会引导登录并创建项目，之后 npx vercel --prod 上线
```

### 方式二：GitHub 导入

1. 把 `frontend_html/` 推到一个 Git 仓库（或推整个 GO_v1 仓库）；
2. 在 [vercel.com](https://vercel.com) → **Add New → Project** 导入该仓库；
3. 若导入的是整个 GO_v1 仓库，在 **Root Directory** 填 `frontend_html`；
   Framework Preset 保持 **Other**，构建命令与输出目录全部留空；
4. 点 **Deploy** 即可，之后每次 push 自动重新部署。

`vercel.json` 已配置：HTML 不缓存（改版即时生效）、css/js 缓存 1 小时、
去除 `.html` 后缀。

### 联机功能：连接 Blob 存储（一次性步骤）

联机对局的状态存放在 **Vercel Blob**（免费额度足够个人使用）。
部署后需关联一次，两种方式任选其一：

- **控制台**：Vercel 项目 → **Storage** 标签 → **Create Database → Blob**
  → **Connect**（连到当前项目即可，环境变量 `BLOB_READ_WRITE_TOKEN`
  会自动注入，随后需 **Redeploy** 一次让函数读到该变量）；
- **CLI**：`npx vercel link` 后执行 `npx vercel storage add blob`（自动关联并注入变量）。

未连接 Blob 时，创建/加入房间会收到明确的服务器错误提示，其余功能不受影响。

## 功能

- **围棋**（9 / 13 / 19 路）
  - 中国规则数子法：子 + 单方围空 + 贴目（9 路 5.5 / 13 路 6.5 / 19 路 7.5）
  - 禁自杀、简单劫（禁止立即回提）、双停一手自动数子并展示领地
  - 「数目」按钮可随时查看当前领地划分与双方点数
- **五子棋**（15 路自由规则）
  - 双人对战，或挑战内置启发式 AI（攻防棋型评分，无神经网络）
  - 人机模式下可「预测着法」（AI 建议点脉冲高亮 6 秒）、交换执子
- **联机对战**（围棋 / 五子棋均支持，经 Vercel 服务器中继）
  - 不依赖 WebRTC 打洞，**任何网络环境（含对称 NAT / 公司内网）都能加入**：
    所有棋局数据经部署在 Vercel 上的自家接口中转（HTTPS 短轮询），
    着法延迟约 0.5～1 秒，回合制棋类完全够用
  - 菜单选「联机对战」→ 创建对局得到 5 位房间码，把 **房间码或含
    `?room=XXXXX` 的链接**发给好友；好友点链接直达加入，或选「加入对局」输码
  - **服务器为权威端**：落子 / 停一手 / 认输 / 悔棋协商全部由服务器用
    与前端同一套规则引擎校验后写入（天然防作弊），双方仅凭会话 token 认席位
  - 悔棋 / 再来一局均需对方弹窗确认；认输即时同步
  - **刷新页面不丢棋局**：棋局存在服务器，地址栏自动带上 `?room=`，
    凭会话 token 刷新后自动认回原席位、恢复整局继续下
  - 对方离线时侧栏有提示，且棋局仍可继续落子（对方回来后自动同步）
- **通用**
  - 悔棋（人机模式自动连 AI 的应手一起撤销）、认输、复盘逐手回放
  - SGF 棋谱保存 / 导入（围棋 GM[1] 中国规则、五子棋 GM[4]，主变解析；
    联机对局中导入禁用以免双方局面不一致，保存双方均可用）
  - WebAudio 合成音效（点击 / 落子 / 提子 / 终局），可开关
  - 键盘：`R` 新对局 · `U`/退格 悔棋 · `A` 预测 · `C` 交换执子 · `D` 数目 ·
    `P` 复盘 · `S` 保存 · `空格`/`←`/`→` 复盘逐手 · `Esc` 退出/返回
  - 菜单支持 `←`/`→` 选择、`Enter` 确认、`Esc` 返回

### 联机说明与限制

- 棋局数据存放在你自己的 Vercel 项目的 Blob 存储里（房间状态约几 KB），
  不经过任何第三方；双方断开（或「断开返回」）时房间即被删除。
- 轮询节奏：己方落子后约 0.45 秒/次，平时约 1.2 秒/次；免费额度内
  双人正常对局绰绰有余。
- 旧版 WebRTC 点对点方案在部分网络下「永远加入不了」（对称 NAT 打洞失败），
  现已整体替换为服务器中继，不再有此问题。
- `file://` 本地打开时联机不可用（没有服务器接口），本地双人 / 人机不受影响；
  联机请访问部署后的 HTTPS 地址。

## 目录结构

```
frontend_html/
├── index.html        页面骨架（菜单 / 联机大厅 / 对局视图 / 隐藏 SGF 文件框 / 模态框挂载点）
├── css/style.css     全部样式（深色菜单 + 象牙色信息栏 + 木纹棋盘配色）
├── js/
│   ├── sound.js      WebAudio 合成音效（无音频文件）
│   ├── go_env.js     围棋规则引擎（提子 / 劫 / 禁自杀 / 数子 / 领地；浏览器与 Node 双端可用）
│   ├── gomoku_env.js 五子棋规则引擎（四方向连五判定；浏览器与 Node 双端可用）
│   ├── gomoku_ai.js  五子棋启发式 AI（纯算法，无模型）
│   ├── sgf.js        SGF 保存 / 下载 / 主变解析
│   ├── ui.js         棋盘 Canvas 绘制 + 主菜单 + 确认框
│   ├── online.js     联机对战（HTTPS 轮询中继客户端 + 联机大厅界面）
│   └── main.js       对局流程控制器（事件 / 侧栏 / 复盘 / 键盘 / 联机同步）
├── api/              Vercel Functions 联机中继（服务器权威校验 + Blob 存储房间状态）
│   ├── _lib.js       共享逻辑（引擎加载 / Blob 读写 / 房间快照，下划线开头不暴露为接口）
│   ├── room.js       POST /api/room         创建房间
│   └── room/[code].js POST /api/room/{code}  加入 / 轮询 / 落子 / 认输 / 悔棋协商 / 关闭
├── package.json      函数依赖声明（@vercel/blob，部署时自动安装）
├── vercel.json       Vercel 部署配置（缓存策略 / cleanUrls）
└── README.md
```

> 说明：脚本均为普通（非 module）脚本并按固定顺序加载，因此无需本地服务器，
> 直接以 `file://` 打开即可运行。
